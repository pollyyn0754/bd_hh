# Парсер вакансий с hh.ru

Проект для сбора и анализа вакансий с сайта hh.ru по заданным компаниям.

## Описание

Программа собирает данные о компаниях и их вакансиях с помощью API hh.ru,
сохраняет их в базу данных PostgreSQL и предоставляет удобный интерфейс для анализа.

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/pollyyn0754/bd_hh
```

2. Установите зависимости:
```bash
pip install poetry
```
```bash
poetry install
```

3. Создайте файл .env и укажите параметры подключения к PostgreSQL:
```python
DB_NAME=hh_parser
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
```

4. Запустите основной скрипт:
```bash
poetry run python main.py
```

### Тестирование
В проекте реализовано комплексное тестирование для обеспечения надежности и корректности работы всех модулей. Тесты находятся в пакете `tests/`.

Запуск всех тестов:
```bash
pytest
```
Запуск тестов с отчетом о покрытии кода:
```bash
pytest --cov=src --cov-report=html
```
После выполнения команды будет сгенерирован детальный HTML-отчет в папке `htmlcov/`, который показывает, какие строки кода были выполнены в процессе тестирования. Общее покрытие функционального кода тестами составляет 97%.
